1 · choose the images for this session

Up to three. Each image gets its own screen window and its own analysis window, so three images means six displays — the limit is monitors, not the computer: the glasses' camera is decoded once no matter how many screens are up. If you are short on displays, open a single analysis window: its fourth panel carries the other images' scanpaths and numbers too.

2 · open one window per screen and drag each to its display

Every screen draws its own four AprilTags — that is what lets one pair of glasses tell the displays apart, so a visitor looking at image 2 never moves image 1's pointer. Open a window, drag it to its monitor or projector, then press start in it (starting one starts the others).

If only the first window appears, the browser blocked the rest as popups — open them one at a time with the buttons above, or allow popups for this site.

Gaze comes from the same bridges as everything else — 8443 for P1, 8444 for P2 — and each window also offers the webcam and a mouse stand-in for testing.
